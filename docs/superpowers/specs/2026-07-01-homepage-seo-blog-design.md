# Дизайн: SEO главной страницы + блог на Keystatic

**Дата:** 2026-07-01  
**Проект:** vfd74.ru — салон дверей ВФД, Челябинск  
**Стек:** Astro 6 + Vue 3 + Tailwind v4, статический билд, rsync-деплой на VPS

---

## 1. Цель

Вывести сайт в топ Яндекса (приоритет) и Google по ключевым запросам в нише дверей Челябинска. Два направления:

1. **SEO-правки главной** — быстрые wins: мета-данные, H1, текстовый контент, новые секции (отзывы, статьи).
2. **Блог на Keystatic** — long-tail трафик через полезные статьи о дверях. Редактор доступен локально через `localhost:4321/keystatic`.

## 3. Блог — архитектура Keystatic

### 3.1 Зависимости

```bash
npm install @keystatic/core @keystatic/astro
```

### 3.2 Конфигурация Keystatic (`keystatic.config.ts` в корне)

Единственная коллекция — `articles`. Поля:

| Поле | Тип | Обязательное | Описание |
|------|-----|-------------|----------|
| `title` | text | да | Заголовок (H1 статьи и `<title>`) |
| `description` | text (multiline) | да | Для `<meta description>` и превью |
| `publishDate` | date | да | Дата публикации |
| `coverImage` | text (url) | нет | URL обложки на Yandex Cloud |
| `body` | document | да | Rich text — тело статьи |

Slug задаётся вручную при создании записи в UI Keystatic (поле "Entry ID"). Используем латинские slug'и (`kak-vybrat-dveri`, не кириллицу) — это важно для SEO URL. Keystatic сохраняет файл как `src/content/articles/{slug}.mdoc`.

### 3.3 Astro content collection (`src/content/config.ts`)

Определяем коллекцию `articles` через `defineCollection` с `z.object` схемой, соответствующей полям Keystatic.

### 3.4 Интеграция в `astro.config.mjs`

Добавляем `keystatic()` в массив `integrations`. Это добавляет маршруты `/keystatic` (UI) и `/api/keystatic` (внутренний API) автоматически.

### 3.5 Новые страницы

#### `/articles` (`src/pages/articles/index.astro`)

- `<title>`: "Статьи о дверях и ремонте — ВФД Челябинск"
- `<meta description>`: "Полезные статьи о выборе дверей, покрытиях, монтаже и интерьере от специалистов салона ВФД в Челябинске."
- Сетка карточек всех статей, отсортированных по `publishDate` (свежие первыми)
- Breadcrumb: Главная → Статьи

#### `/articles/[slug]` (`src/pages/articles/[slug].astro`)

- `<title>`: `{article.title} — ВФД Челябинск`
- `<meta description>`: `{article.description}`
- H1: `{article.title}`
- Дата публикации (visible + `<time datetime>`)
- Обложка (если есть)
- Rich text тело статьи
- Breadcrumb: Главная → Статьи → {title}
- JSON-LD: `BlogPosting` schema (см. §3.6)

### 3.6 JSON-LD для статей

```json
{
  "@context": "https://schema.org",
  "@type": "BlogPosting",
  "headline": "{title}",
  "description": "{description}",
  "image": "{coverImage}",
  "datePublished": "{publishDate}",
  "author": {
    "@type": "Organization",
    "name": "ВФД — Салон дверей в Челябинске",
    "url": "https://vfd74.ru"
  },
  "publisher": {
    "@type": "Organization",
    "name": "ВФД — Салон дверей в Челябинске",
    "logo": { "@type": "ImageObject", "url": "https://vfd74.ru/favicon.svg" }
  },
  "mainEntityOfPage": {
    "@type": "WebPage",
    "@id": "https://vfd74.ru/articles/{slug}"
  }
}
```

JSON-LD для хлебных крошек `BreadcrumbList` добавляется рядом.

### 3.7 Sitemap

В `astro.config.mjs` sitemap уже настроен с кастомным `serialize()` и `filter()`. Страницы `/articles` и `/articles/*` попадут автоматически. Нужно добавить правило priority:

- `/articles` → `priority: 0.7`, `changefreq: weekly`
- `/articles/*` → `priority: 0.6`, `changefreq: monthly`
